## Overview
A high-performance modern web application built for **Eco Green Solar (Green Energy)** located in Rajkot, Gujarat. Built with:
- **Vite + React 18 + TypeScript**
- **GSAP (GreenSock) & ScrollTrigger** for smooth bi-directional animations
- **Lenis Smooth Scroll** with zero jank
- **Three.js & React Three Fiber** for 3D elements
- **Responsive Mobile & Desktop Design** (Zero layout cut-offs, anti-flicker GPU acceleration)
- **Interactive 3D Product Catalog** and **3D Spec Flip Cards**

## Getting Started

### Prerequisites
- Node.js (v18 or higher)
- npm or yarn

### Installation
```bash
npm install
```

### Development Server
```bash
npm run dev
# Server running at http://localhost:3000/
```

### Production Build
```bash
npm run build
```

## Features
- **Cinematic Multi-Style Hero Transitions**: Dynamic Ken-Burns zoom, architectural curtain wipes, and depth-of-field transitions.
- **Two-Way 3D Flip Product Cards**: Hover on desktop and click/tap to toggle back and forth on touch devices.
- **Auto-Hiding Smart Navbar**: Slides out of view on scroll down, restores on reverse scroll up.
- **Responsive Sinking WhatsApp Button**: Gently sinks into a circular icon on scroll down, expands to full button on scroll up.
- **Exact Coordinates Integration**: Google Maps embed pinned to `22.21273267178387, 70.60438963429085` (Gajanand Industrial Area, Lodhika, Rajkot).
- **Lighthouse Performance & SEO**: LocalBusiness JSON-LD schema, canonical URLs, semantic HTML5.
